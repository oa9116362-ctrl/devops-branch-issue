# DevOps Workshop : Branch & Issue

รายวิชา: DevOps  
ระดับ: ปวช. 2  

Repository นี้ใช้สำหรับ **ใบงานที่ 5 (งานคู่)**  
เรื่อง การใช้ Issue, Branch และ Pull Request บน GitHub

---

## 🎯 วัตถุประสงค์
- ฝึกการทำงานร่วมกันเป็นทีม
- เรียนรู้การใช้ Issue เพื่อมอบหมายงาน
- เรียนรู้การใช้ Branch เพื่อแยกการทำงาน
- ฝึกการส่งงานด้วย Pull Request

---

## 🧑‍🤝‍🧑 สมาชิกกลุ่ม
> ✏️ ให้นักเรียนแก้ไขเฉพาะส่วนนี้ใน Branch ของตนเอง

- นักเรียนคนที่ 1 : สุภัชชา เจริญสาริกรณ์
- นักเรียนคนที่ 2 : ศิรประภา มหาสมุทร
---

## 📌 ข้อกำหนดในการทำงาน
- ห้ามแก้ไขไฟล์ใด ๆ บน branch `main`
- นักเรียนคนที่ 2 เป็นผู้แก้ไขไฟล์ README.md
- ต้องส่งงานผ่าน Pull Request เท่านั้น
